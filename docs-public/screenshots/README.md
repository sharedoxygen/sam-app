# Screenshots

This directory contains screenshots for the main README.md file.

## Required Screenshots

1. **executive-dashboard.png** - Executive Dashboard view showing high-level KPIs
2. **team-analytics.png** - Team Performance Analytics view
3. **task-management.png** - Task & Pipeline Management interface

## Guidelines

- **Format:** PNG (preferred) or JPG
- **Width:** 1200-1600px recommended for clarity
- **Content:** Ensure no sensitive/real data is visible
- **Naming:** Use lowercase with hyphens (kebab-case)

## How to Add Screenshots

1. Take screenshots of the application views
2. Save them with the exact filenames listed above
3. Place them in this directory
4. The main README.md will automatically display them
